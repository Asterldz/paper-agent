# 阅读策略与受控反馈适配

## 架构

阅读流程基于 LangGraph、LangChain 和 Zod，包含规划、工具执行、回答与引用检查。实现入口与工具说明见 [Agent 架构](agent-project.md)。

- [阅读 Skill](../agent-skills/paper-reading/SKILL.md) 定义证据优先、参考论文追踪和回答规范。
- [进化 Skill](../agent-skills/paper-reading-evolution/SKILL.md) 将有效反馈转成受限策略候选。
- Skill 是应用加载的指令资源；权限、参数验证和版本控制由宿主代码执行。

## 反馈处理

```text
显式反馈 → 分类 → 生成候选 → 字段与父版本校验
                                  ↓
                     用户审核 / 可选明确偏好自动采用
                                  ↓
                           新策略版本 → 可回滚
```

反馈按表达偏好、阅读策略、工程故障和不明确反馈分类。确定性偏好可本地处理，其余最多一次模型请求。HTTP 错误或 PDF 选区故障应进入工程排查，不通过修改阅读策略掩盖。

## 策略边界

可变字段仅包括 `answerStyle`、`referenceDepth` 和 `termDetail`。模型不能调整工具权限、预算、评测规则或源码，也不能修改进化器自身。

每个请求使用固定策略快照。候选包含父版本，过期候选不能覆盖更新后的策略；回滚产生新版本，相关缓存按版本隔离。

明确、持久的表达偏好可由用户选择自动采用。模型提出的一般策略仍需审核。一次性要求只影响当前任务，不自动转为永久偏好。

个人策略只作用于对应设备的用户配置，不应作为所有使用者的默认规则。论文正文和工具返回内容是证据，不是修改策略的授权。

## 执行约束

- 阅读任务最多 4 轮规划、8 次工具调用、150 秒。
- 规划请求无自动重试，正文请求最多一次。
- 文献切换或取消后，旧任务不得更新新的结果。
- 工具返回实际来源与访问状态，摘要、题录不能冒充全文。
- 划选翻译使用独立快速路径，不强制进入反馈处理流程。

## 验证与后续工作

机制测试覆盖越权字段、候选审核、竞争更新、策略回滚、取消与缓存隔离。行为评测场景见 [反馈评测基线](../agent-skills/paper-reading-evolution/references/feedback-baseline.md)。

当前未实现答案质量自动评分与晋升、后台无人值守迭代、跨设备记忆或模型训练。引用检查验证证据身份和位置，不等同于语义事实支持评估。

后续质量评测应使用固定文献、基线版本、独立保留集和相同模型参数，并记录来源支持、完整性、延迟及调用成本。候选生成器不应有权修改评测标准。
