# 发布与维护检查

## 源码仓库范围

依赖目录 `node_modules/`、构建目录 `dist/`、安装包目录 `release/`、本地环境文件和缓存不应提交。安装包可单独发布为 Release 附件。

`public/assistant-cat-v2.png` 用于头像与样式回退，五张 v4 WebP 图集用于动画。`desktop/` 与 `scripts/` 分别支持桌面应用和浏览器本地启动。动态导入的 Agent 模块和 Skill 资源属于运行依赖。

## 发布检查清单

- 检查待提交文件、忽略规则和密钥模式；同时审查图片、历史提交及日志中的个人信息。
- 在干净安装环境运行类型检查、lint、单元测试和生产构建。
- 执行依赖安全审计，验证升级兼容性。
- 保持中英文 README、启动命令、许可和实现状态一致。
- 公开发布前验证签名、平台兼容性及安装流程。
- 发布说明区分源码仓库、在线服务与桌面安装包。
