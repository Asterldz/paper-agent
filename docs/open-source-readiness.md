## 文件结论

| 类别 | 检查结果与建议 |
| --- | --- |
| `node_modules/`（约 1.3 GB） | 安装依赖，已忽略；保留本机使用，不提交 |
| `dist/`（约 60 MB） | 生成的服务构建产物，已忽略，不是源码 |
| `release/`（约 343 MB） | 桌面产物，已忽略；将来可作为 Release 附件 |

体积为本机磁盘占用快照，不是下载大小。`git ls-files -ci --exclude-standard` 本轮返回空，未发现受忽略规则覆盖却仍被跟踪的文件。新增文件主要是桌面支持、测试、CI、许可和文档，均有用途。

当前源码/文档定向搜索未发现 `/Users/`、`/var/folders/`、`wxid_` 路径；排除了依赖、构建产物、锁文件和增量缓存。这不代表不存在其他个人信息或密钥。
